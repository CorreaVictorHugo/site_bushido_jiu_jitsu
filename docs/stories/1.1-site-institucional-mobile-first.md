# Story 1.1 — Site institucional mobile-first Bushido

## Status

Ready for Review

## User Story

Como integrante da Bushido, quero uma presença digital responsiva e visualmente forte para representar a equipe e apresentar o projeto no portfólio, sem comunicar captação comercial.

## Acceptance Criteria

- [x] A página identifica a equipe como Bushido no primeiro viewport.
- [x] O layout é projetado primeiro para telas móveis e se adapta ao desktop.
- [x] A abertura segue a referência monocromática sem copiar marca ou textos de terceiros.
- [x] O conteúdo não oferece aula experimental e não inventa professor, endereço, títulos ou horários.
- [x] A página contém base para manifesto, pilares, rotina e memória da equipe.
- [x] Cada seção possui conteúdo editorial suficiente para explicar sua função sem depender de dados ainda não confirmados.
- [x] Em desktop, cada movimento de rolagem encaixa a próxima seção como um capítulo; em telas menores, o comportamento não impede a leitura do conteúdo.
- [x] Menu móvel, links internos, foco por teclado e preferência por movimento reduzido funcionam.
- [x] A imagem principal é original e está armazenada localmente.
- [x] Verificações automatizadas do projeto passam.
